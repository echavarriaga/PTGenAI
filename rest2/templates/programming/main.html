This page has been designed to provide a testing and evaluation environment for PortableRho, a domain-specific language (DSL) based on JSON and integrated with the REST architecture of RestRho. PortableRho allows modeling and defining RESTful interfaces in a flexible and scalable way, offering an agile mechanism for the communication and orchestration of distributed services. One of its most notable features is the dynamic transformation of templates using Generative Artificial Intelligence, which enables the adaptation and modification of Handlebars templates in an automated and intelligent manner. This capability facilitates real-time customization of responses and data structures, thus optimizing the development of data-oriented services and enhancing the integration experience in distributed environments.

API RestRho

RestRho includes DSL-JSONs named DBRestRho y SQLRho with the aim of dynamically defining and deploying a RESTful API server (an API designed under the REST web architecture, characterized by functioning with HTTP requests such as GET, POST, PUT, and DELETE). RESTRho has the ability to transform JSON results and the capacity to apply Handlebars Template Engines (a tool that separates logic and design in web content generation).

Frameworks JavaScripts

The JavaScript Frameworks used in the creation of this page are listed below:

  • RhoEngine (v.2.1):The core of our approach has been implemented in the Rho Execution Engine (RhoEngine for short). Its goal is to evaluate programs written in customizable JSON-based DSLs (namely, RhoCode or DSL-JSON), and then to run them in the Rho Interpreter in order to get the result (namely, a RhoObject) in the web-client or the web server.
